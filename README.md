 # Seguridad Ciudadana

Problema
Municipios requieren visualizar delitos y factores asociados.
## Datos sugeridos
    • Delitos por comuna. 
    • Horarios. 
    • Tipo de delito. 
    • Edad de involucrados. 
    • Sectores geográficos. 

## Objetivo del dashboard

    Detectar:
        • zonas de mayor riesgo, 
        • horarios críticos, 
        • tendencias delictuales. 

    Indicadores clave
        • Delitos por sector. 
        • Delitos por horario. 
        • Evolución mensual. 
        • Tipo de delito predominante.



# Desarrollo de la evaluación

## Parte 1: Proceso ETL
    Los estudiantes deberán:
        1. Identificar fuentes de datos relevantes. 
        2. Descargar y conectar datasets. 
        3. Limpiar datos: 
            ◦ eliminar nulos, 
            ◦ corregir formatos, 
            ◦ eliminar duplicados. 
        4. Transformar datos: 
            ◦ crear columnas calculadas, 
            ◦ agrupar categorías, 
            ◦ generar métricas. 
        5. Cargar los datos transformados. 

## Parte 2: Análisis y visualización

    Cada grupo deberá:
        1. Definir KPIs estratégicos. 
        2. Aplicar análisis descriptivo. 
        3. Construir dashboard interactivo. 
        4. Incorporar: 
            ◦ gráficos adecuados, 
            ◦ filtros, 
            ◦ segmentadores, 
            ◦ mapas o series temporales si aplica. 
        5. Presentar conclusiones y propuesta de valor. 

# Entregables
    Cada grupo deberá entregar:
        • Dashboard funcional. 
        • Dataset transformado. 
        • Breve explicación del proceso ETL. 
        • Conclusiones estratégicas. 

    Requerimientos mínimos del dashboard
    
    El dashboard debe incluir:
        • mínimo 4 visualizaciones distintas, 
        • al menos 3 KPIs, 
        • diseño coherente, 
        • interpretación de resultados.
